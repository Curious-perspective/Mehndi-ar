# Mehndi AR

Live mehndi (henna) on any hand that comes in front of the phone camera — a single HTML file, no build step.

- Hand tracking: MediaPipe Hands (loaded from jsDelivr)
- Patterns: Mandala, Arabic vine, Minimal · fresh / dark shade
- Front/back camera, snapshot with the pattern baked in
- Works on Android Chrome and iOS Safari over HTTPS

Open: https://curious-perspective.github.io/mehndi-ar/
